# Create: Brass Compass

A brass compass that remembers every lodestone it has been shown and points at the one you choose.
Right-click a lodestone to save it under a name; right-click anywhere else to pick a destination.
Sneak to use the compass as if it were not there.

Requires Minecraft 26.2, Fabric Loader, Fabric API and Create Fly. MIT (LICENSE); credits in NOTICE.
Releases carry the jar and its SHA-256 in the notes; see CHANGELOG.md for what each version holds.
